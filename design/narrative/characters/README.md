# Character Sheets

One sheet per character. Every sheet has the same sections, so the cast can be compared at a glance:

1. **Role and canon**: who they are in the story, and the canon level of each fact.
2. **Backstory and motivation**: where they come from and what they want.
3. **Personality and speech**: traits, quirks, how they talk, and lines they would never say.
4. **Visual design**: build, hair, outfit, colours (hex values match the code), accessories and signature weapon.
5. **Gameplay role**: unlock rule, brawl move, and how they help the player.
6. **Open questions**: what the author still needs to decide.

## Rules for every sheet

- All hunters are female (author decision). The Lanternboys are boys.
- Colours are the hex values used in the code. If a sheet changes a colour, the code changes too.
- Canon levels: **Established** (in the game now and approved), **Provisional** (drafted, can change), **Under Review** (open question).
- Lines of dialogue stay under 120 characters (see `.claude/rules/narrative.md`).
